# Atypical Maker Mac Apps

Małe aplikacje na Maca od [EnderNoch](https://github.com/EnderNoch) (Atypical Maker).
Każda robi jedną rzecz, wygląda jak część macOS 26/27 i bierze z systemu wszystko, co system
już daje: język, jasny i ciemny wygląd, kolor akcentu, suwak Liquid Glass i styl ikon.

*English: small Mac apps that do one thing each and follow the system for everything —
language, light/dark, accent color, Liquid Glass and icon style. Download from each app's repo.*

## Instalacja

Każda aplikacja to plik zip w swoim repozytorium: otwórz go i przeciągnij aplikację do folderu
Aplikacje. Aplikacje nie są notaryzowane, więc przy pierwszym uruchomieniu trzeba je raz
dopuścić: Ustawienia systemowe → Prywatność i ochrona → **Otwórz mimo to**.

Wymagają macOS 26 lub nowszego na Macu z procesorem Apple.
